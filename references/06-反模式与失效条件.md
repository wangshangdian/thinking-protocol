# 06 · 反模式与失效条件

## 一、本技能自身的失效条件（什么时候**不要**用它）

| 情形 | 应该怎么做 |
|---|---|
| 单步任务、纯查询、结果完全可逆无成本 | 直接做。走流程是浪费时间 |
| 用户已经给了完整规格并明确说"就这么做" | 执行，不要再澄清 |
| 紧急、需要立刻行动 | 先做可逆的那部分，事后补裁定 |
| 用户明确表示只是想聊聊、不想要方案 | 就聊 |
| 已经有明确规范（如公司流程、标准模板） | 遵循规范，不要另起一套 |

**最重要的失效条件**：把这个技能**仪式化**。
如果每次回复都要走完整八项协议，用户会弃用整个技能——这比没有技能更糟。

判据：**用户是否在往前走？** 如果流程让你不断提问、反复确认、迟迟不出结果，就是仪式化了。

## 二、反模式清单

| # | 反模式 | 症状 | 纠正 |
|---|---|---|---|
| 1 | 仪式化 | 小任务也铺文档、走全套 | 先分档；轻档只做一句话裁定 |
| 2 | 追问不收敛 | 一轮又一轮地问，永远到不了"清楚" | 2 轮上限 → 转最小可逆探针 |
| 3 | 问能自己查到的事 | "请问这个库支持 Python 吗？" | 先自己查，再问不可推断的 |
| 4 | 讨好式同意 | "这个思路很棒" + 直接开工 | 强制先写「不成立的部分」 |
| 5 | 为反对而反对 | 每条都挑刺，显得深刻 | 必须写「成立的部分」+ 下一步 |
| 6 | 空洞第一性原理 | "本质是为了提高效率" | 必须能推出"该做什么/不该做什么" |
| 7 | 延伸清单爆炸 | 一次提 8 条延伸 | 硬限额 3 条，按绑定约束排序 |
| 8 | 文献真 = 本项目真 | 拿别人的基准结论直接下结论 | 检查假设是否匹配（指标/规模/成本） |
| 9 | 假发现 | 只跟基线比就宣布发现结构 | 两级对照：循环位移 + 打乱保分布 |
| 10 | 结论无失效条件 | 结论只写了「成立」 | 每条结论补「什么情况下作废」 |
| 11 | 把不确定说成确定 | 语气自信但证据薄弱 | 三档置信度 + 标注不确定处 |
| 12 | 悄悄改写用户的命题 | 澄清着澄清着，问题变成另一个 | 澄清阶段先记录原话为「待裁定命题」 |
| 13 | 用延伸回避主结论 | 主问题没答，先讲一堆相关话题 | 先给主判定，再给延伸 |
| 14 | 同一事实写两处 | 章程写了、契约又复述 | 单一事实源：只引用不复述 |
| 15 | 用上下文硬扛复杂度 | 长会话越做越糊 | 外置到文件，用编号隔离 |
| 16 | 没有停止条件 | 一直在优化，从不定"什么算够好" | 开工前写否决条件；事后不许改判据（见 §四） |
| 17 | 用沉没成本当理由 | "都做了三天了，再试试" | 只问边际：从今天起再投一单位，还划算吗 |
| 18 | 同一个模型既做又审 | 自己审自己的产出，说"没问题" | 换**跨厂商**的另一个模型复核（见 08） |
| 19 | 拿榜单/聚合排名定架构 | "X 排第一，所以换 X" | 先问"我要它干的事属于哪个轴"，再找那个轴的证据 |

## 三、失效条件怎么写

格式：
```
【失效条件】当 <可观察的前提> 不再成立时，本条结论作废。
   例：样本量 < 200 时，本结论的 IC 估计不可信。
       ——触发后可用的替代动作：<降级方案>
```

要点：
- 必须是**可观察**的（数字、状态、事件），不是"如果我判断错了"。
- 尽量写**触发后怎么办**，而不只是"作废"。
- 结论被推翻时，**不要删旧结论**，改写状态为 `⛔作废` 并注明原因——它告诉你此路不通。

## 四、停止规则（什么时候该收手）

**为什么单列一节**：本技能大部分内容在教「怎么继续做对」，
但没有一条在教「**什么时候别再做了**」。而「一直优化下去」是最容易失血的方向——

> ⚠️ 已观察到的失效模式：**「更强的一方指出遗漏」这个序列不收敛**。
> 每换一个更强的模型/更严的评审，它都会找出新的遗漏，因为它知道得更多。
> 照单全收 ⇒ 研究精力持续花在「优化一个还没决定要不要建的引擎的涡轮型号」上。

### 三条规则

| # | 规则 | 落地动作 |
|---|---|---|
| 1 | **开工前先写否决条件** | 判据写成「若 X 成立则停止」，X 必须是**可观察的数字/状态**。写在动手之前，不是之后 |
| 2 | **判据事后不许改** | 锁定后调参 = 自己给自己发通行证。要改判据，必须**作废本轮并说明为什么**，不能悄悄换 |
| 3 | **沉没成本不参与判断** | 「已经做了三天」不是继续的理由。只问：**从今天起，再投一单位资源，期望收益是否仍高于成本？** |

### 停手 ≠ 失败（这条最难接受）

停下来的三种**正当**结局，都应写进结论里，而不是假装没发生：

| 结局 | 怎么记 |
|---|---|
| **证伪** | 「假设 X 不成立」+ 证据。**这是资产**——它告诉你此路不通，别人不用再走 |
| **无法判定** | 「当前样本量/数据不支持回答」+ **需要什么条件才能回答** |
| **不值得继续** | 「边际收益已低于成本」+ 在什么条件下值得重启 |

⇒ **禁止把"没做出来"写成"基本可行"。**

## 五、自我怀疑触发检查（怀疑走偏时过一遍）

1. 我现在是在**回答问题**，还是在**回避问题**？
2. 我说的话里，哪一句是**没有依据**的？
3. 如果有人**反驳我**，他会拿什么证据？
4. 我把用户的原话，改动过吗？
5. 这个结论**什么情况下会作废**？
6. 我提的东西，命中**绑定约束**了吗？
7. 用户是不是已经在往前走？还是在被我问住？

第 7 条是总闸。被问住 = 本技能使用失败。
