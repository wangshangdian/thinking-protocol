# 08 · 模型分工与纠偏（元层协议）

> **这一节回答的不是"怎么想"，而是"该用谁来想、怎么问"。**
> ⚠️ 本文件分两层：**原则层**（长期有效）与 **快照层**（会过时，标了日期）。
> 引用快照层的内容前，先确认它是否还在有效期内。

---

## 一、为什么需要这一节（它防的是什么）

三个具体的失效模式：

| 失效模式 | 症状 |
|---|---|
| **① 一个模型干所有事** | 用它写代码、又用它审自己的代码 → **自己审自己，等于没审** |
| **② 拿榜单当结论** | "X 排在 Y 前面，所以换 X" —— 榜单测的东西可能和你要的东西不是一回事 |
| **③ 结果好得不像真的，直接采信** | 没有人去复核，因为它"看起来很强" |

⭐ 第 ③ 条是**唯一一个应该在流程里硬编码的触发器**。

## 二、原则层（长期有效）

### 2.1 四个轴，不是一个排行榜

"哪个模型更强"是个伪问题。至少按四个轴分开看，而且**每个轴都有自己的偏差**：

| 轴 | 测什么 | 已知偏差 |
|---|---|---|
| **人类偏好榜** | 人对着两个答案选一个 | 偏**讨喜**（格式漂亮、自信、篇幅长），不偏**正确**。长回答有系统性优势 |
| **能力分榜** | 标准化题目的正确率 | 题目口径与你的任务不同；**多为"无工具态"** |
| **工具态 vs 无工具态** | 带检索/代码执行时的表现 | ⭐ **同一模型这两个状态可以完全不是一回事**——你的实际用法是哪种，就看哪种的分数 |
| **聚合站** | 把上面几种揉成一个数 | 数据滞后、口径不一、权重不透明。**只当索引，不当依据** |

⇒ **规则：先问"我这次要它干的事，属于哪个轴"，再去看那个轴的证据。**

### 2.2 五个操作规则

| # | 规则 | 落地动作 |
|---|---|---|
| 1 | **什么时候必须切强模型** | ① 要**定方向/定架构**（错了代价大）② 结果**好得不像真的** ③ 要**审查已经做完的东西** ④ 涉及不可逆成本 |
| 2 | **长任务中途复核** | 长链任务不要只在开头和结尾看。中途抽一个**中间产物**让另一个模型复核 |
| 3 | ⭐ **怎么问，比问谁重要一个数量级** | 同一个模型，问法不同结果差一个量级。要给它：**你的原话主张 + 已知约束 + 要求它反驳你** |
| 4 | ⭐⭐ **强模型的意见是输入，不是结论** | 与 P2 同构：**"上游说得对" ≠ "对本项目对"**。它知道得更多，所以它永远能找出新的"遗漏"——**这个序列不收敛**（见 `references/06 §四 停止规则`） |
| 5 | **成本不是决策变量** | 一次错误方向的成本远高于多问一次的 API 费用。别为了省几毛钱做错方向 |

### 2.3 提问模板（规则 3 的具体形态）

```
【背景】我在做 <什么>，当前已确认的约束是 <硬约束>。
【我的主张】我认为 <原话>，依据是 <……>。
【请你做的】不要复述我的话。请：
  ① 指出这个主张里哪一部分**不成立**，以及**依据**；
  ② 如果有成熟方法/文献已经解决过它，给出**正式名字 + 出处**；
  ③ 说明这个方法的**失效条件**（什么情况下它不适用）。
【约束】不确定就说不确定，不要为了完整而编。
```
⭐ 关键是 **③「失效条件」**：正规军的边界往往正是野路子的坑。

### 2.4 禁忌清单

- ❌ 同一个模型**既做又审**（自审等于没审）
- ❌ 拿一个聚合排名决定架构
- ❌ 把"更强的模型说 X"直接当结论写进文档
- ❌ 用它没工具时的分数推断它有工具时的表现（反之亦然）
- ❌ 把长回答/格式漂亮等同于正确
- ❌ **不记录"这是谁在什么条件下给的判断"** —— 结论没有来源，以后无法复核

## 三、快照层（⏳ 会过时，用前先核对）

**记录日期：2026-09-18**（来自一个具体项目的实测分工，仅作示例，**不是推荐**）

| 岗位 | 用什么 | 为什么 |
|---|---|---|
| 日常执行（写代码、跑数据、改文档） | 快而便宜的主流模型 | 量大，错了重跑成本低 |
| **事实核查 / 数字核对** | 另一个厂商的模型 | **跨厂商**才有独立性；同厂商同代际的盲区高度相关 |
| **方法论审查 / 长链推理** | 当期最强的推理模型 | 只在规则 1 的四个触发器下用 |

⚠️ **模型的版本号和排名变化极快（周级）**。
⇒ **不要把具体型号写进长期规则**；本节的表格只用来回答"该按哪几个轴分工"。

## 四、输出模板

```
【这次该用谁】任务类型 → 轴 → 具体模型（含"无工具/有工具"约定）
【为什么不是更强的那个】<一句：代价 / 不需要 / 会引入什么偏差>
【交叉验证安排】谁审谁；审的是哪个中间产物
【本次判断的来源】模型 + 时间 + 是否带工具  ← 写进结论，便于日后复核
```
